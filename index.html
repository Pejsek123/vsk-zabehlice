Supabase JS SDK v2 • Dokumentace architektury

Jak je aplikace 100% napojena na Supabase

Tato aplikace obsahuje plnohodnotné asynchronní volání metod Supabase JS SDK v2 (auth.signUp, auth.signInWithPassword, dotazy na tabulky profiles, children, courses, enrollments a attendance).

1. Nastavení přihlašovacích údajů

V horní části JavaScriptu tohoto souboru (index.html) jsou jasně vyznačené konstanty:

// Konstanty na začátku JS skriptu:
const SUPABASE_URL = 'https://tvuj-projekt.supabase.co';
const SUPABASE_KEY = 'tvuj-anon-public-klic';
  • Přejděte do Project Settings → API ve vašem Supabase dashboardu.
  • Zkopírujte Project URL do SUPABASE_URL.
  • Zkopírujte Project API key (anon / public) do SUPABASE_KEY.

2. Režim provozu & Persistence

Aplikace disponuje inteligentním duálním adaptérem:

Připojeno k Supabase: Když zadáte reálné údaje, kód provádí přímé asynchronní síťové dotazy přes oficiální REST & Auth endpointy Supabase.
Offline / Sandbox persistence: Při výchozích zástupných údajích aplikace ukládá data přes sandboxové rozhraní notebookAppApi, takže všechny změny (nové děti, docházka, schválení adminem) přetrvají i po zavření okna.

Kompletní SQL schéma pro Supabase SQL Editor

Zkopírujte tento SQL kód a vložte jej do vašeho Supabase SQL Editoru pro vytvoření všech tabulek a bezpečnostních politik.
